# 📘 Episode 02 – CREATE TABLE, INSERT & SELECT Explained

Welcome to **Episode 02** of the **SQL Tutorial for Data Engineers** series.

In this episode, you'll learn how data is stored inside a SQL database. We begin by understanding tables, rows, columns, and common data types before creating our first SQL table, inserting records, and retrieving data using the `SELECT` statement.

---

## 🎯 Learning Objectives

By the end of this episode, you'll be able to:

- Understand what a table is
- Differentiate between rows and columns
- Learn common SQL data types
- Create a table using `CREATE TABLE`
- Insert records using `INSERT INTO`
- Retrieve data using `SELECT`
- Understand why SQL keywords are written in uppercase (Best Practice)

## 💻 Practice Assignment

Create a table named **Student** with the following columns:

| Column | Data Type |
|---------|-----------|
| StudentID | INT |
| StudentName | VARCHAR(100) |
| Age | INT |
| Course | VARCHAR(100) |

### Tasks

- Create the Student table
- Insert at least **5 records**
- Display all records using:

```sql
SELECT *
FROM Student;
```
